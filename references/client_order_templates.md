## 2. "Frontend (Field/Execution)" vs. "Backend (Corporate/System)" Calibration Matrix

When writing bullets for candidates with **< 1 year of experience** (Fresh Graduates or 1–11 months working), always use the **Frontend / Execution** column so they pass User/Manager technical screening without appearing to over-claim:

| Field / Domain | "Frontend" (On-Site / Daily Execution — For <1 Yr Exp) | "Backend" (System / Policy Architecture — For 2+ Yrs Exp) |
| :--- | :--- | :--- |
| **HSE / K3** | `Safety Patrol`, `Hazard Identification`, `Toolbox Meeting (TBM)`, `Assertive Communication` menegur kepatuhan APD, cek fisik APAR/P3K, pengawasan `Permit to Work (PTW)` & `JSA` di lokasi. | Merancang kerangka sistem `ISO 45001` korporat dari nol, memimpin audit eksternal `SMK3 / CSMS`, menyusun strategi anggaran K3 tahunan perusahaan. |
| **Admin / Finance** | Input jurnal harian, verifikasi kelengkapan invoice & PO, rekonsiliasi mutasi bank harian, pembuatan faktur pajak (`e-Faktur`), pengelolaan *petty cash* & pengarsipan dokumen. | Merancang sistem akuntansi perusahaan, *tax planning* strategis korporat, audit laporan keuangan konsolidasi tahunan. |
| **HR / Recruitment** | *Job posting*, *screening* CV, penjadwalan interview, administrasi & skoring tes psikologi (`DISC/Kraepelin`), input database karyawan & BPJS, rekap absensi bulanan. | Merancang struktur skala upah (*grading salary*), menyusun Peraturan Perusahaan (PP) tingkat korporat, restrukturisasi organisasi. |
| **Software / IT** | Membangun fitur modul spesifik, membuat *endpoint* `REST API`, menulis *query* database, *bug fixing*, containerization `Docker`, & integrasi UI komponen. | Merancang arsitektur *cloud enterprise* multi-region dari nol atau memimpin puluhan tim engineer. |
